# 空间推断网络 v2：真实数据探索结论（2026-11-05）

**这是 2026 道路快照对 2023–2026 事件的回溯代理实验，不是获批历史路网。** PR #20 的严格独立认证研究维持 NO-GO；P3 经独立核验连接仍为 0，不能迁移 P1/P2 的性能到 P3。目标为暂定的 96 车道 `recovery_confirmation_v1` 30 分钟**内恢复确认**，不是 Proposal 所称的恢复开始。

- 96 个真实车道单位：95 个方向相容候选映射，其中预先设定的高置信条件通过 **27 个**，其余 68 个为歧义推断；1 个无方向相容候选。保留全部 736 条原始候选记录。95/96 **不是**匹配正确率。
- 单独的推断有向道路图有 **62,625** 条带 INTERSECTION 支持的源弧端点转接，**不证明合法转弯**；P1 得 **42** 条 canonical 推断检测器邻接、43 条候选路径；P2 得 **6** 条邻接、7 条候选路径。原先 74 个 PR #20 候选对不等于合格推断连接。
- 真实 as-of 邻路明细：P1 28,056 条事件-邻居观测 / 17,550 个有邻居事件；P2 1,243 条 / 1,182 个事件。逐条保留检测器、弧序列、**网络**米数、观测/可得/原始来源水位时间与源 SHA-256，未使用候选覆盖 CSV 冒充特征。
- 30m 已知标签且有邻路观测的训练/验证/测试：**P1 7,611 / 4,680 / 3,933**（训练阳性/阴性 1,587/6,024；验证 1,061/3,619；测试 689/3,244）；**P2 446 / 456 / 191**（205/241；168/288；83/108）。P2 测试只有 191 个事件/9 个目标检测器，不适合强泛化断言。P3 0/0/0。

### 方向与地理对照（P1 同 3,933 测试事件；M1 ROC-AUC：RF / XGBoost）

| 控制 | RF | XGBoost |
|---|---:|---:|
| C1 直线邻近 | .7304 | .7325 |
| C2 无方向合并 | .7413 | .7470 |
| C3 推断有向 | .7523 | .7588 |
| C4 同时刻/5km 同区邻居置换 | .7466 | .7516 |
| M0 本群体 | .7250 | .7290 |

C5 P2 有向 M1 为 .6643 / .6750，但**不同群体不能与 P1 直接相减**。C4 仅 4,078 条全队列事件行实际可置换，多数同时间/区域格子不能有效置换；C4 仍有较大收益，说明共享同时段或区域信息可能解释相当部分提升，不能称已证实有向道路传播。观察到**回溯预测信息增加**（P1/P2 M1 的点估计较 M0 高），却不能据此判断历史道路物理关系已获验证、因果有效或可部署。C1 仅地理直线距离，不能与网络路径距离混用。
